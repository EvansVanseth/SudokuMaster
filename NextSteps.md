# Hito 3.5 Inclusión de Landing Page

## Próximo Prompt: 

Crea una landing page, con un banner donde el usuario pueda loguearse o se muestre información en caso de que esté logueado. Añade también a este banner un texto de Darse de alta.

Crea un componente nuevo para que un usuario se pueda registar, donde deberán poner la información necesaria.

La landing page debe mostrar algunos tableros a medio hacer, algún texto de curiosidades sobre los sudokus y algun texto atrayente para darse de alta, en el que se podrá acceder al mismo componentes que hemos hablado en anterioridad para poder darse de alta.

Prepara un plan para realizar este cambio.
