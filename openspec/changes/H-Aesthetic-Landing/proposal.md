# Proposal: Landing Page Aesthetic and UX Improvements

## Problem
The current landing page lacks clear guidance for new users, has layout issues on the hero section, and needs better branding and attribution.

## Proposed Changes
1. **Hero Section**: Stack text and buttons vertically in the center.
2. **CTA Enhancement**: 
   - Center the 'Create account' button.
   - Improve button styling (padding, size).
   - Add author credits: "Designed & Programmed by [GitHub Logo] EvansVanseth ([Portfolio](https://portfolio-juanalonso.vercel.app/))".
3. **Branding**:
   - Update favicon to a simple square with a number.
   - Update browser tab title (remove "(Beta)").
4. **UX**:
   - Add inviting text under 'Partidas que te esperan' section.

- `src/app/pages/LandingPage.tsx`
